# Simpsons 当日集金 Web

Simpsons の試合参加費（2026年は一律300円）を、試合当日にスマホから受領確認するための小さいWebアプリです。

## 目的

- 基本は当日300円を受け取る。
- 現金とPayPayが混在しても、同じ「受領履歴」に残す。
- 管理者の単純なチェック欄ではなく、受領日時・支払方法・受領IDを持つ記録を正式な根拠にする。
- 現金受領時はその場で受領票を表示できる。
- 誤操作は履歴を削除せず「取消」にする。
- 同じ試合・同じ選手への二重受領をバックエンド側でも防ぐ。

## データ元

既存の Google Sheets 台帳を使います。

必要なタブ:

- `試合`
- `参加者`
- `受領履歴`

### 試合の切り替え

- サイトを開いたときは、`試合` タブで「完了」「中止」ではない最初の試合を自動表示。
- 「この試合を完了」で状態を `完了` にすると、次の未完了試合へ切り替える。
- 過去/未来の試合はプルダウンから手動でいつでも確認できる。
- 深夜0時など、時刻だけで勝手には切り替えない。

## 当日画面

未収者を上に固定して、各選手に次の2ボタンを表示します。

- `現金 ¥300`
- `PayPay確認`

PayPay はAPI連携ではなく、PayPay側の送金履歴を確認したうえで「確認済み」として記録する設計です。

受領すると:

1. サーバー時刻で受領履歴を1件追加。
2. 選手を「受領済み」側へ移動。
3. 受領票を表示可能。
4. 直後に「取り消す」を表示。
5. 取消時も元の受領行は削除せず、状態だけ `取消` に変更。

## Apps Script での起動

最も簡単なのは、集金台帳の Google Sheets に紐づけて使う方法です。

1. 集金台帳を開く。
2. **拡張機能 → Apps Script**。
3. このフォルダ内のファイルをApps Script側に作成する。
   - `Code.gs`
   - `Index.html`
   - `Styles.html`
   - `App.html`
   - `appsscript.json`
4. **デプロイ → 新しいデプロイ → ウェブアプリ**。
5. 試作中はアクセスを自分だけにする。
6. 発行されたURLをiPhoneのホーム画面へ追加すれば、当日はほぼアプリのように使える。

スタンドアロンApps Scriptとして使う場合は、Script Properties に `SPREADSHEET_ID` を設定してください。
